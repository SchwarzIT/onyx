A dialog overlay / modal that presents a list of options for single selection. Commonly used inside the [navigation bar](/components/navigation/nav-bar) to select the light/dark mode, application language and more.

## Examples

### Basic

Open the modal and select a value by either clicking an option are selecting it via keyboard by using the arrow keys. Each option has a required label and can optionally display an icon and description text.
