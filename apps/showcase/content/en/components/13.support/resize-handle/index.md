An interactive border or grip that users can drag to dynamically resize an element.

## Examples

The following interactions are supported:
- drag: Press and hold the border to resize the element by moving your cursor
- cancel: Press the "Escape" key while dragging to cancel the resizing and revert the width back to the previous value
- reset: Double click the border to reset the width back to the original value

### Basic

The resize handle supports left and right alignment.
