---
title: Loading indicator
componentName: OnyxLoadingIndicator
---

A visual indicator that signals an ongoing, indeterminate background process after an user interaction. For visualizing the loading progress on initial page load without any user interaction, use the [skeleton](/components/support/skeleton) component or property of supported components instead.
