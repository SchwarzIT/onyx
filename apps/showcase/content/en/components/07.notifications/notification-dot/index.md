Displays a dot indicator for an arbitrary component. Useful to highlight that there is more information available when e.g. clicking the button.

## Examples

### Basic

The notification dot can technically be wrapped around any element, although we most recommend to use a button such as an [icon button](/components/buttons/icon-button) or [nav button](/components/navigation/nav-button). The dot supports several colors depending on the semantic meaning. See our [color documentation](/introduction/foundation/colors#colors) for more information on when to use which color.
