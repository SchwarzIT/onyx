The dialog is used to provide additional information to the user. It is always attached to a parent element, similar to a [tooltip](/components/feedback/tooltip).

## Examples

### Basic

The dialog content is fully customizable. It contains a header and body section as well as an optional footer. The dialog placement can be adjusted if needed using the `position` and `alignment` property.
