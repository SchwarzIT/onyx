A breadcrumb component is a secondary navigation element that displays a user's current location within the application's structural hierarchy. It enables users to understand their current context and trace their path back to parent pages.

## Examples

### Basic

The breadcrumb is always positioned above the main page content and contains the previous and current page of the application's navigation hierarchy.

The container breadcrumb can optionally be used and placed directly below the nav bar.
