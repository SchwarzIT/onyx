A bottom bar is a navigation bar at the bottom of a page, component or whole application. Preferably used together with the [page layout](/components/layouts/page-layout) component. The bottom bar is positioned sticky so the content becomes scrollable if its too long.

## Examples

### Basic

The default bottom bar shows right aligned action buttons. Optional left aligned actions can be display if needed.

:component-example{name="Basic" layout="fullWidth"}

### Modal

The bottom bar can also be used in combination with the [modal](/components/feedback/modal).

:component-example{name="Modal"}

### Form

When used together with a form where the submit button is placed inside a bottom bar, the button is often technically placed outside of the form so you need to manually "connect" the form with the button. See the [form](/components/form-elements/form#external-submit-buttons) component for further information how to connect external submit buttons.
