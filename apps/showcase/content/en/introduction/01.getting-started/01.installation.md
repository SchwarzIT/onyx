## Basic setup

Please choose for which tool you want to install our design system:

::content-tabs
#vue
<auth-only>

<div class="onyx-grid">
<link-card class="onyx-grid-span-8" headline="Vue Blueprint" link="https://vue-blueprint.schwarz">

We **strongly recommend** to use the Vue Blueprint to start your project. It is the official starter application for Schwarz Group internal projects, created and maintained by us - the Onyx team.

Follow the instructions below only if you are **NOT using the Vue Blueprint**. Otherwise, everything will already be set up for you.

</link-card>

<steps>

  ::step
  #headline
  Step 1: Create a basic Vue application

  #default
  Follow the official [Vue installation guide](https://vuejs.org/guide/quick-start.html) to create a new Vue application if not already done.
  ::

  ::step
  #headline
  Step 2: Install Onyx

  #default
  Next, install our `sit-onyx` npm package:

  :npm-install-code-tabs{packages="sit-onyx"}
  ::

  ::step
  #headline
  Step 3: Add styles and plugin

  #default
  Finally, import the styles and register our Vue plugin in your `main.ts` file. Make sure to provide your router and i18n if used to enable the integration with [vue-router](https://router.vuejs.org/) and [vue-i18n](https://vue-i18n.intlify.dev/).

  The `global.css` file is optional but strongly recommended if the whole application is build with onyx. Our components are built to not have any side affects on global application styles like `<body>` etc. so they can also be easily integrated with other design systems.

  ```ts [main.ts]
  import "sit-onyx/style.css";
  import "sit-onyx/global.css";

  import { createApp } from "vue";
  import { createOnyx } from "sit-onyx";

  const onyx = createOnyx({
    // if you are using Vue Router, make sure to pass it here be enable the router integration
    router,
    // if you are using i18n, make sure to pass your locale here to enable the i18n integration
    i18n: {
      locale: i18n.global.locale,
    },
  });

  const app = createApp(App);
  app.use(onyx);
  ```

  ::

</steps>

#nuxt
<steps>

  ::step
  #headline
  Step 1: Create a basic Nuxt application

  #default
  Follow the official [Nuxt installation guide](https://nuxt.com/docs/4.x/getting-started/installation) to create a new Nuxt application if not already done.
  ::

  ::step
  #headline
  Step 2: Add Nuxt module

  #default
  Next, install our Nuxt module in your existing project:

  :npm-install-code-tabs{packages="@sit-onyx/nuxt"}

  and then add it to your `nuxt.config.ts` file. **Important**: If you are also using the [@nuxtjs/i18n](https://i18n.nuxtjs.org/) module, make sure to move `@sit-onyx/nuxt` **before** `@nuxtjs/i18n`.

  ```ts [nuxt.config.ts]
  export default defineNuxtConfig({
    modules: ["@sit-onyx/nuxt"],
    onyx: {
      // optional module options here...
    },
  });
  ```

  ::

</steps>

## Browser support

Our design system works best with the following browser versions. We also perform automated testing for compatibility. Other browsers and older versions might also work but we do not guarantee full compatibility.

:browser-support

<prose-details>

<prose-summary>Need to support older browsers?</prose-summary>

To also support older browser versions, use `lightningcss` with [@vitejs/plugin-legacy](https://www.npmjs.com/package/@vitejs/plugin-legacy) or [nuxt-vite-legacy](https://www.npmjs.com/package/nuxt-vite-legacy).

::content-tabs
#vue
```ts [vite.config.ts]
import { defineConfig } from "vite";
import legacy from "@vitejs/plugin-legacy";

export default defineConfig({
  plugins: [
    legacy({
      targets: ["chrome >= 120"],
    }),
  ],
  build: {
    cssMinify: "lightningcss",
  },
  css: {
    lightningcss: {
      targets: {
        chrome: 120,
      },
    },
  },
});
```

#nuxt
```ts [nuxt.config.ts]
import { defineNuxtConfig } from "nuxt/config";

export default defineNuxtConfig({
  modules: ["nuxt-vite-legacy"],
  // use `lightningcss` to support syntax lowering for modern CSS features
  vite: {
    build: {
      cssMinify: "lightningcss",
    },
    css: {
      lightningcss: {
        targets: {
          chrome: 120,
        },
      },
    },
  },
  // use the `nuxt-vite-legacy` module to inject polyfills for relevant user agents
  legacy: {
    targets: ["chrome >= 120"],
  },
});
```
::

</prose-details>
