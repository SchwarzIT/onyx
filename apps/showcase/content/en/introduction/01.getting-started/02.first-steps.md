## Layout

We **strongly recommend** to use our app and page layout components to structure your application since they provide easy and consistent layout options, manage scroll containers correctly and provide system-level components to the application.

<steps>

::step
#headline
App layout

#default
The app layout should be placed once at the root of your application and serves as the shell for global navigation and main content. It also provides system-level components such as [toasts](/components/feedback/toast) and [notifications](/components/notifications/notifications).

  ::content-tabs
  #vue
  ```vue [App.vue]
  <script lang="ts" setup>
  import { OnyxAppLayout, OnyxNavBar, OnyxNavItem } from "sit-onyx";
  import { RouterView } from "vue-router";
  </script>

  <template>
    <OnyxAppLayout>
      <template #navBar>
        <OnyxNavBar app-name="Example app">
          <OnyxNavItem label="Page 1" link="/page-1" />
          <OnyxNavItem label="Page 2" link="/page-2" />
        </OnyxNavBar>
      </template>

      <RouterView />
    </OnyxAppLayout>
  </template>
  ```


  #nuxt
  ```vue [app/app.vue]
  <template>
    <OnyxAppLayout>
      <template #navBar>
        <OnyxNavBar app-name="Example app">
          <OnyxNavItem label="Page 1" link="/page-1" />
          <OnyxNavItem label="Page 2" link="/page-2" />
        </OnyxNavBar>
      </template>

      <NuxtRouteAnnouncer />

      <NuxtLayout>
        <NuxtPage />
      </NuxtLayout>
    </OnyxAppLayout>
  </template>

  ```
  ::
::

::step
#headline
Page layout

#default
The page layout should the used on every page to ensure standardized spacing and scroll containers. It also provides dedicated slots for easily integrating sidebars, footers and main page content.

  ::content-tabs
  #vue
  ```vue [views/HomeView.vue]
  <script lang="ts" setup>
  import { OnyxHeadline, OnyxPageLayout } from "sit-onyx";
  </script>

  <template>
    <OnyxPageLayout>
      <OnyxHeadline is="h1">Hello World</OnyxHeadline>
    </OnyxPageLayout>
  </template>
  ```


  #nuxt
  In Nuxt, we usually recommend to create a [Nuxt layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts) to define the page layout for all pages. You can also also add a global footer here that should be displayed at the bottom of every page if needed.
  For individual pages with custom layouts, you can also [pass props to the layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts#passing-props-to-layouts-44) or [override the layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts#overriding-a-layout-on-a-per-page-basis) completely.

  ```vue [app/layouts/default.vue]
  <script lang="ts" setup>
  defineSlots<{
    /**
    * Main page content.
    */
    default(): unknown;
  }>();
  </script>

  <template>
    <OnyxPageLayout>
      <slot></slot>
    </OnyxPageLayout>
  </template>
  ```

  #figma
  For every new frame / page in your design, apply the `onyx/color/base/background/tinted` variable as fill color.
  ::

## Grid settings

Another key step is configuring your application's layout grid. We recommend defining your content's maximum width and alignment early on.

On very large screens, stretching content across the entire width often degrades the user experience. Our standard recommendation is to cap the content at 1920px (the `lg` breakpoint) and use center alignment, as shown in the example below. Set the corresponding CSS classes on your root app component.


For all available options and documentation, please refer to our:

#dev
```html [App.vue]
<OnyxAppLayout class="onyx-grid-max-lg onyx-grid-center">
  <!-- app content here... -->
</OnyxAppLayout>
```

#ux
Apply a layout grid to your frame / page by selecting on of our pre-defined grid layouts in the "Layout guide" menu. Ensure to select to correct grid size depending on the size of your frame / breakpoint.
