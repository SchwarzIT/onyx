## Colors

With a wide variety of pre-defined color palettes that adapt automatically between light and dark mode, we offer a highly flexible foundation to build consistent, accessible, and visually appealing user interfaces across any digital product.

::info-card{headline="Variables or hard-coded colors?" color="neutral"}
Always use the CSS or Figma variables shown below instead of hard-coding hex or RGB values. Utilizing variables ensures your application remains fully themeable and transitions seamlessly between light and dark mode. For a deeper dive into our design tokens, please refer to the [variables](/introduction/foundation/variables) documentation.
::

Every color family in this design system is structured into **three functional sub-tokens** to ensure consistent application:

## Usage

::content-tabs
#dev
 Use the [color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color-scheme) CSS property to manage theme switching. Simply define it on the root element for a global effect, or apply it directly to specific components for localized theming.
 
 To ensure backward compatibility with older libraries, you can alternatively apply a `.dark` CSS class. For optimal results and future-proofing, we strongly recommend using the `color-scheme` property instead.

```css [Apply dark mode]
:root {
  color-scheme: dark;
}
```

### Automatic light & dark mode

We highly recommend syncing your application's theme with the user's system settings.

 Check out the instructions below to set this up using Vue or Nuxt. To let users override the system default, simply add our [OnyxColorSchemeMenuItem](https://storybook.onyx.schwarz/?path=/docs/navigation-navbar-modules-colorschememenuitem--docs) or [OnyxColorSchemeDialog](https://storybook.onyx.schwarz/?path=/docs/navigation-navbar-modules-colorschemedialog--docs) to your navbar for interactive switching (auto, light, dark).


  ::content-tabs
  #vue
  <steps>

    ::step
    #headline
    Install VueUse

    #default
    If not already done, install the [VueUse](https://vueuse.org/) npm package:

    :npm-install-code-tabs{packages="@vueuse/core"}
    ::

    ::step
    #headline
    Enable automatic light & dark mode

    #default
    Add the [useColorMode()](https://vueuse.org/core/useColorMode/) composable from VueUse to easily support the automatic light & dark mode detection:

    ```vue [App.vue]
    <script setup lang="ts">
    import { useColorMode } from "@vueuse/core";
    import { useThemeTransition } from "sit-onyx";

    const { store: colorScheme } = useColorMode({ disableTransition: false });
    useThemeTransition(colorScheme);
    </script>
    ```
    ::
  </steps>

  <steps>
