## MCP

The Onyx [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server connects your AI coding assistant (e.g. Gemini, Claude, Cursor) directly to our design system. It provides live, version-accurate component specifications, documentation, variables, best-practice skills and more.

### Installation

::auth-only

  ::info-card
  ---
  headline: SBX Kit
  ---
  When using the Schwarz internal [Docker Sandbox (SBX) kit](https://developer.schwarz/docs/tooling/devex-tools/opencode/opencode-getting-started), our MCP is already installed so no manual installation is needed.
  ::


::

::tabs
---
label: Installation methods
initialValue: remote
size: h3
---

  ::onyx-tab
  ---
  label: Remote
  value: remote
  ---
  Connect directly via HTTPS without installing locally. Future updates to the MCP will be available automatically.

  ```json [opencode.json]
  {
    "$schema": "https://opencode.ai/config.json",
    "mcp": {
      "onyx": {
        "type": "remote",
        "url": "https://mcp.onyx.schwarz",
      }
    }
  }
  ```

  ::

  ::onyx-tab
  ---
  label: Local
  value: local
  ---
  Run the MCP locally on your machine with a fixed version. Install the MCP:

  <steps>

    ::step
    #headline
    Step 1: Install MCP

    #default
    Install the `@sit-onyx/modelcontextprotocol` package:

    :npm-install-code-tabs{packages="@sit-onyx/modelcontextprotocol" dev}
    ::

    ::step
    #headline
    Step 2: Configure your coding agent

    #default
    Install the `@sit-onyx/modelcontextprotocol` package:

    ```json [opencode.json]
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "onyx": {
          "type": "local",
          "command": ["npx", "-y", "onyx-mcp", "-r"],
        }
      }
    }
    ```
    ::

  </steps>
  ::
::

## Figma Code Connect

Onyx bridges the gap between design and development by pairing our comprehensive Figma UI library with our technical Vue component library. Every Figma component is mapped directly to its corresponding Vue component using [Figma Code Connect](https://developers.figma.com/docs/code-connect).

By establishing a 1:1 link between Figma designs and technical components, you gain significant advantages across your workflow:

<div class="onyx-grid">

::content-card
---
headline: Accurate Code Snippets
class: onyx-grid-span-4
---
In Figma Dev Mode, developers directly see ready-to-use Vue code snippets reflecting the exact properties, variants, and states configured in the design, eliminating manual translation.
::

::content-card
---
headline: Superior AI Code Generation
class: onyx-grid-span-4
---
When AI coding assistants or Figma generate code from design screens, Code Connect guides them to use authentic Onyx Vue components instead of creating custom HTML and CSS from scratch.
::

::content-card
---
headline: Design System Consistency
class: onyx-grid-span-4
---
Keeps design and code in sync by mapping Figma components directly to Onyx Vue components, establishing a shared vocabulary and preventing UI drift between design libraries and production apps.
::

</div>
