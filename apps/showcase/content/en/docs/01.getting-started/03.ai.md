## MCP

The Onyx [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server connects your AI coding assistant (e.g. Gemini, Claude, Cursor) directly to our design system. It provides live, version-accurate component specifications, documentation, variables, best-practice skills and more.

### Installation

::tabs
---
label: Installation methods
initialValue: remote
size: h3
---

    ::onyx-tab
    ---
    label: Remote
    value: remote
    ---
    Connect directly via HTTPS without installing locally. Future updates to the MCP will be available automatically.

    ```json [opencode.json]
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "onyx": {
          "type": "remote",
          "url": "https://mcp.onyx.schwarz",
        }
      }
    }
    ```

    ::

    ::onyx-tab
    ---
    label: Local
    value: local
    ---
    Run the MCP locally on your machine with a fixed version. Install the MCP:

    <steps>

        ::step
        #headline
        Step 1: Install MCP

        #default
        Install the `@sit-onyx/modelcontextprotocol` package:

        :npm-install-code-tabs{packages="@sit-onyx/modelcontextprotocol" dev}
        ::

        ::step
        #headline
        Step 2: Configure your coding agent

        #default
        Install the `@sit-onyx/modelcontextprotocol` package:

        ```json [opencode.json]
        {
          "$schema": "https://opencode.ai/config.json",
          "mcp": {
            "onyx": {
              "type": "local",
              "command": ["npx", "-y", "onyx-mcp"],
            }
          }
        }
        ```
        ::

    </steps>
    ::
::
