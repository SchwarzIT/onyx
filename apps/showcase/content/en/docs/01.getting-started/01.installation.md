## Basic setup

Select your platform or framework to get started:

::content-tabs
#vue
<auth-only>

<link-card headline="Vue Blueprint" link="https://vue-blueprint.schwarz">

We **strongly recommend** using the Vue Blueprint - the official starter application for internal Schwarz Group projects. It is preconfigured and maintained by the Onyx team.

Follow the instructions below only if you are **NOT using the Vue Blueprint**.

</link-card>

<br />
</auth-only>

<steps>

  ::step
  #headline
  Step 1: Create a Vue application

  #default
  Follow the official [Vue installation guide](https://vuejs.org/guide/quick-start.html) to create a new Vue application if needed.
  ::

  ::step
  #headline
  Step 2: Install Onyx

  #default
  Install the `sit-onyx` package:

  :npm-install-code-tabs{packages="sit-onyx"}
  ::

  ::step
  #headline
  Step 3: Add styles and plugin

  #default
  Import the styles and register the Vue plugin in your `main.ts` file. Pass your [router](https://router.vuejs.org/) and [i18n](https://vue-i18n.intlify.dev/) instances to enable integrations.

  `global.css` is optional but strongly recommended when the entire application is built with Onyx. Components are scoped to prevent side effects on global elements like `<body>`, making it safe to integrate with existing styles or other design systems.

  ```ts [main.ts]
  import "sit-onyx/style.css";
  import "sit-onyx/global.css";

  import { createApp } from "vue";
  import { createOnyx } from "sit-onyx";

  const onyx = createOnyx({
    // pass Vue Router instance to enable router integration
    router,
    // pass locale to enable i18n integration
    i18n: {
      locale: i18n.global.locale,
    },
  });

  const app = createApp(App);
  app.use(onyx);
  ```

  ::

</steps>

#nuxt
<steps>

  ::step
  #headline
  Step 1: Create a Nuxt application

  #default
  Follow the official [Nuxt installation guide](https://nuxt.com/docs/4.x/getting-started/installation) to create a new Nuxt application if needed.
  ::

  ::step
  #headline
  Step 2: Add Nuxt module

  #default
  Install the Nuxt module:

  :npm-install-code-tabs{packages="@sit-onyx/nuxt"}

  Then add it to your `nuxt.config.ts`. **Important**: If you also use [@nuxtjs/i18n](https://i18n.nuxtjs.org/), place `@sit-onyx/nuxt` **before** `@nuxtjs/i18n`.

  ```ts [nuxt.config.ts]
  export default defineNuxtConfig({
    modules: ["@sit-onyx/nuxt"],
    onyx: {
      // optional module options...
    },
  });
  ```

  ::

</steps>

## Browser support

Our design system is tested and optimized for modern browsers. Older browser versions may work, but full compatibility is not guaranteed.

:browser-support

<prose-details>

<prose-summary>Need to support older browsers?</prose-summary>

To also support older browser versions, use `lightningcss` with [@vitejs/plugin-legacy](https://www.npmjs.com/package/@vitejs/plugin-legacy) or [nuxt-vite-legacy](https://www.npmjs.com/package/nuxt-vite-legacy).

::content-tabs
#vue
```ts [vite.config.ts]
import { defineConfig } from "vite";
import legacy from "@vitejs/plugin-legacy";

export default defineConfig({
  plugins: [
    legacy({
      targets: ["chrome >= 120"],
    }),
  ],
  build: {
    cssMinify: "lightningcss",
  },
  css: {
    lightningcss: {
      targets: {
        chrome: 120,
      },
    },
  },
});
```

#nuxt
```ts [nuxt.config.ts]
import { defineNuxtConfig } from "nuxt/config";

export default defineNuxtConfig({
  modules: ["nuxt-vite-legacy"],
  // use `lightningcss` to support syntax lowering for modern CSS features
  vite: {
    build: {
      cssMinify: "lightningcss",
    },
    css: {
      lightningcss: {
        targets: {
          chrome: 120,
        },
      },
    },
  },
  // use the `nuxt-vite-legacy` module to inject polyfills for relevant user agents
  legacy: {
    targets: ["chrome >= 120"],
  },
});
```

</prose-details>
