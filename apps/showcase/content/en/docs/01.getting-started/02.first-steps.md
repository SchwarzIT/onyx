## Layout

We **strongly recommend** using the [app](/components/layouts/app-layout) and [page layout](/components/layouts/page-layout) components to structure your application. They provide consistent layout structures, correct scroll container management, and system-level components.

<steps>

::step
#headline
App layout

#default
The [app layout](/components/layouts/app-layout) is placed once at the root of your application. It serves as the shell for global navigation and main content, while hosting system-level components like [toasts](/components/feedback/toast) and [notifications](/components/notifications/notifications).

  ::content-tabs
  #vue
  ```vue [App.vue]
  <script lang="ts" setup>
  import { OnyxAppLayout, OnyxNavBar, OnyxNavItem } from "sit-onyx";
  import { RouterView } from "vue-router";
  </script>

  <template>
    <OnyxAppLayout>
      <template #navBar>
        <OnyxNavBar app-name="Example app">
          <OnyxNavItem label="Page 1" link="/page-1" />
          <OnyxNavItem label="Page 2" link="/page-2" />
        </OnyxNavBar>
      </template>

      <RouterView />
    </OnyxAppLayout>
  </template>
  ```


  #nuxt
  ```vue [app/app.vue]
  <template>
    <OnyxAppLayout>
      <template #navBar>
        <OnyxNavBar app-name="Example app">
          <OnyxNavItem label="Page 1" link="/page-1" />
          <OnyxNavItem label="Page 2" link="/page-2" />
        </OnyxNavBar>
      </template>

      <NuxtRouteAnnouncer />

      <NuxtLayout>
        <NuxtPage />
      </NuxtLayout>
    </OnyxAppLayout>
  </template>

  ```
  ::
::

::step
#headline
Page layout

#default
Use [page layout](/components/layouts/page-layout) on every page to ensure standardized spacing and scroll containers. It provides dedicated slots for sidebars, footers, and page content.

  ::content-tabs
  #vue
  ```vue [views/HomeView.vue]
  <script lang="ts" setup>
  import { OnyxHeadline, OnyxPageLayout } from "sit-onyx";
  </script>

  <template>
    <OnyxPageLayout>
      <OnyxHeadline is="h1">Hello World</OnyxHeadline>
    </OnyxPageLayout>
  </template>
  ```


  #nuxt
  In Nuxt, create a [Nuxt layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts) to define the structure across pages. You can also add a global footer here.
  For custom pages, [pass props to the layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts#passing-props-to-layouts-44) or [override the layout](https://nuxt.com/docs/4.x/directory-structure/app/layouts#overriding-a-layout-on-a-per-page-basis).

  ```vue [app/layouts/default.vue]
  <script lang="ts" setup>
  defineSlots<{
    /**
    * Main page content.
    */
    default(): unknown;
  }>();
  </script>

  <template>
    <OnyxPageLayout>
      <slot></slot>
    </OnyxPageLayout>
  </template>
  ```

  #figma
  Create a new frame sized for your project (e.g. Full HD, 1920x1080px). Apply the `onyx/color/base/background/tinted` variable as the fill color so the background adapts across light and dark modes.
  ::
::

## Grid settings

Configure your application grid by defining a maximum width and alignment early on.

On wide screens, stretching content across the full width impairs readability. We recommend capping content at 1920px (the `lg` breakpoint) with center alignment. Apply these utility classes to your root component:


For all options, see the:

<div class="onyx-grid">
<link-card class="onyx-grid-span-4" headline="Breakpoints & Grid documentation" link="/docs/foundation/breakpoints-and-grid"></link-card>
</div>


::content-tabs
#dev
```html [App.vue]
<OnyxAppLayout class="onyx-grid-max-lg onyx-grid-center">
  <!-- app content here... -->
</OnyxAppLayout>
```

#ux
Apply a layout grid to your frame by selecting one of our predefined grid layouts in the "Layout guide" menu. Be sure to select the grid matching your frame size / breakpoint.
