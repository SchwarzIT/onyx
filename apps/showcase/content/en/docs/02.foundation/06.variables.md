Design variables represent shared design attributes such as color, typography, and spacing. They ensure consistency and streamline cross-platform development. Variables should always be favored over hardcoded values so that [colors](/docs/foundation/colors) adapt across light/dark themes and spacing responds to the active [density](/docs/foundation/density).

::info-card{headline="Developers and designers"}
Design variables align developers and designers through a shared naming convention and unified visual language.
::

## Architecture

The variable architecture consists of three layers. Only semantic variables are intended for direct use in applications:

<layout-container>
<steps>

::step
#headline
Global variables

#default
Global variables store raw, context-agnostic design values (such as primitive colors and unit scales). They are **not** intended to be used directly in application code.

::

::step
#headline
Semantic variables <onyx-tag label="used by applications" color="success" />

#default
Semantic variables map raw values to functional use cases and adapt across light and dark modes. Developers and designers should always build components using semantic variables.

::

::step
#headline
Component variables

#default
Component variables are reserved for internal component definitions and unique state overrides. They are **not** intended for external use.

::

</steps>

:variable-architecture-preview

</layout-container>

<br />

All variables share the `onyx` prefix to avoid collisions with application styles. In code, variables use kebab-case dashes; in Figma, they use slash notation. For example, `--onyx-color-text-icons-neutral-intense` in CSS corresponds to `onyx/color/text/icons/neutral/intense` in Figma.

::content-tabs
#dev
All variables are exposed as [CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties) and referenced with `var()`:

```css [Apply variables in CSS]
.my-component {
  color: var(--onyx-color-text-icons-neutral-intense);
}
```

#ux
Open Figma's variable panel and select "Libraries" to inspect and apply variables. For details, refer to the [Figma documentation](https://help.figma.com/hc/en-us/articles/15343107263511-Apply-variables-to-designs).
::
