## Colors

Predefined color palettes adapt automatically between light and dark mode.

::info-card{headline="Variables vs. hardcoded colors"}
Always use CSS or Figma variables instead of hardcoded hex values. This ensures components adapt properly when switching between light and dark modes. For details, see the [variables](/docs/foundation/variables) documentation.
::

## Usage

::content-tabs
#dev
To toggle between light and dark mode, set the [color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color-scheme) CSS property on the root or on a specific container:

```css [Apply dark mode]
:root {
  color-scheme: dark;
}
```

For compatibility with older tooling, Onyx also supports the `.dark` class, though `color-scheme` is preferred.

### Automatic light/dark mode

To adapt automatically to system preferences, use the approaches below for Vue or Nuxt. You can also integrate [OnyxColorSchemeMenuItem](/components/navigation/color-scheme-menu-item) or [OnyxColorSchemeDialog](/components/navigation/color-scheme-dialog) to allow manual theme switching.

  ::content-tabs
  #vue
  <steps>

    ::step
    #headline
    Install VueUse

    #default
    Install the [VueUse](https://vueuse.org/) package:

    :npm-install-code-tabs{packages="@vueuse/core"}
    ::

    ::step
    #headline
    Enable automatic light/dark mode

    #default
    Use the [useColorMode()](https://vueuse.org/core/useColorMode/) composable from VueUse:

    ```vue [App.vue]
    <script setup lang="ts">
    import { useColorMode } from "@vueuse/core";
    import { useThemeTransition } from "sit-onyx";

    const { store: colorScheme } = useColorMode({ disableTransition: false });
    useThemeTransition(colorScheme);
    </script>
    ```
    ::
  </steps>

  #nuxt
  <steps>

    ::step
    #headline
    Install Nuxt module

    #default
    Install the [@nuxtjs/color-mode](https://color-mode.nuxtjs.org/) module:

    :npm-install-code-tabs{packages="@nuxtjs/color-mode"}
    ::

    ::step
    #headline
    Enable automatic light/dark mode

    #default
    Register `@nuxtjs/color-mode` in your Nuxt config:

    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      modules: ["@nuxtjs/color-mode"],
    });
    ```
    ::
  </steps>
  ::
