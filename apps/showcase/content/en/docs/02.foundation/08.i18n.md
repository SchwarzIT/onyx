## Available languages

English (`en-US`) is enabled by default. Additional languages must be registered during application setup. Once registered, component translations automatically synchronize with your active application locale.

::info-card{headline="AI transparency note" color="primary" icon="stars-AI"}
English and German translations are curated manually. Other languages are AI-generated and might have been (partially) reviewed by native speakers.
::

## Installation

::content-tabs
#vue
Connect your existing [vue-i18n](https://vue-i18n.intlify.dev/) instance to Onyx by passing the current locale and message bundles:

```ts [main.ts]
import { createOnyx } from "sit-onyx";
import onyxDE from "sit-onyx/locales/de-DE.json";
import { createI18n } from "vue-i18n";

const i18n = createI18n({
  // existing vue-i18n setup...
});

const onyx = createOnyx({
  i18n: {
    locale: i18n.global.locale,
    // Locale keys (e.g. "de-DE") must match your vue-i18n setup exactly
    messages: { "de-DE": onyxDE },
  },
});

createApp(App).use(i18n).use(onyx);
```

Whenever the `vue-i18n` locale changes, Onyx updates its internal component translations automatically.

#nuxt
When using `@sit-onyx/nuxt`, locales configured in `@nuxtjs/i18n` are detected and loaded automatically.

If your locale codes omit region subtags (e.g. using `es` instead of `es-ES`), specify the complete [BCP 47 language tag](https://developer.mozilla.org/en-US/docs/Glossary/BCP_47_language_tag) in the `language` property:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@sit-onyx/nuxt", "@nuxtjs/i18n"],
  i18n: {
    locales: [
      { code: "de-DE" },
      // When code is "es", provide the full BCP 47 code in "language"
      { code: "es", language: "es-ES" },
    ],
  },
});
```
