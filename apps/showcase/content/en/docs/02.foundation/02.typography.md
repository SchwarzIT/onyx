## Font families

The design system uses two font families to avoid visual clutter: a sans-serif and a monospace typeface. Visual contrast is achieved through variations in weight and size rather than combining multiple font families.

By default, these Open Source typefaces are used, optimized for legibility on digital screens:


<steps>

::step
#headline
Default: Source Sans 3 <onyx-tag label="default" />

#default
Clear, modern, and approachable. View on [Google Fonts](https://fonts.google.com/specimen/Source+Sans+3).
::

::step
#headline
Monospace: Source Code Pro

#default
Precise and readable. Designed for data-dense layouts and code blocks. View on [Google Fonts](https://fonts.google.com/specimen/Source+Code+Pro).
::

</steps>

To support diverse brand identities, a [variable-based](/docs/foundation/variables) architecture is used so font families can be customized easily. See [custom font families](#custom-font-families) below.

## Usage

Instead of arbitrary pixel values, we provide semantic text roles that express functional intent. Whenever possible, use built-in typography components for headlines, links, and text.

<steps>

::step

Headlines

#default
Use the [OnyxHeadline](/components/navigation/headline) component for headlines.

Heading levels `h5` and `h6` are supported for semantic HTML hierarchy but share the visual styling of `h4`.

## Installation

::content-tabs
#dev

Font families are not bundled by default to optimize bundle size and build performance. You **must** install your chosen font packages manually, otherwise browsers fall back to system defaults.

<steps>

  ::step
  #headline
  Install font families

  #default
  We recommend installing fonts using [Fontsource](https://fontsource.org):

  :npm-install-code-tabs{packages="@fontsource-variable/source-sans-3 @fontsource-variable/source-code-pro"}

  ::

  ::step
  #headline
  Add imports

  #default
  Import the font stylesheets in your application entry file:

    :::content-tabs
    #vue
    ```ts [main.ts]
    import "@fontsource-variable/source-sans-3";
    import "@fontsource-variable/source-code-pro";
    ```

    #nuxt
    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      css: ["@fontsource-variable/source-sans-3", "@fontsource-variable/source-code-pro"],
    });
    ```
    :::

  ::

</steps>

### Custom font families

To use custom fonts instead of the defaults:

<steps>

  ::step
  #headline
  Install custom font families

  #default
  Install your preferred font packages or host the font files locally.

  ::

  ::step
  #headline
  Override default font families


  #default
  Override the default font variables with your custom font families:

  ```css [Override font families]
  :root {
    --onyx-font-family-Source-Sans-3-Variable: "Font family name", sans-serif;
    --onyx-font-family-Source-Code-Pro-Variable: "Font family name", monospace;
  }
  ```

  ::

</steps>
